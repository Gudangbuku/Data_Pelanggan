☁️ Koneksi Google Sheets (Cloud Backup)

Backup data ke Google Sheets agar bisa dibuka dari device & browser manapun. Setup sekali saja:

  1. Buka script.google.com — login akun Google
  2. Klik Proyek baru, hapus kode lama, paste kode di bawah ini:
  3. Simpan (Ctrl+S), beri nama proyek
  4. Klik Deploy → New deployment → Web app → Execute as: Me → Access: Anyone → Deploy
  5. Klik Authorize access → pilih akun Google → Allow
  6. Copy URL yang muncul, paste di bawah:
